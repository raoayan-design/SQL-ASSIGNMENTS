PYTHON OOP: FOUR PILLARS ASSIGNMENT
==================================

Files included:
Q1.py - Student Result Manager (Encapsulation)
Q2.py - Secure Bank Account (Encapsulation)
Q3.py - Employee Roles (Inheritance)
Q4.py - Vehicle Rental System (Inheritance)
Q5.py - Notification Dispatcher (Polymorphism)
Q6.py - Checkout Discount Calculator (Polymorphism)
Q7.py - Shape Calculator (Abstraction)
Q8.py - Payment Gateway (Abstraction)

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the extracted folder in VS Code or a terminal.
3. Run each file separately:

   python Q1.py
   python Q2.py
   ...
   python Q8.py

Only Python's standard library is used.

NOTES
-----
- Each file contains a small test/demo section under if __name__ == "__main__".
- Q1 demonstrates public, protected, and private attributes. Python's double
  underscore uses name mangling; it is not absolute security.
- Q2 is an educational encapsulation example, not a production banking system.
- Q6 includes GoldCustomer as the requested extension.
- Q8 includes MobileWalletPayment as an additional payment method.

Review the code and make sure you can explain each class and method before
submitting it as your own work.
